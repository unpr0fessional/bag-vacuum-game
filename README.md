# сумка-пылесос · 1.0.3

Настольная браузерная 3D-игра по авторскому видео Камиля. Три уровня: собрать заказ
со стола, не забить сумку лишними предметами и не попасться на ловушках.

[Играть онлайн](https://unpr0fessional.github.io/bag-vacuum-game/?release=1.0.3) ·
[Релиз 1.0.3 и архив игры](https://github.com/unpr0fessional/bag-vacuum-game/releases/tag/v1.0.3).
Нужны клавиатура, мышь и современный браузер с WebGL. Игра и материалы работают локально,
без CDN, аккаунта, аналитики или внешних запросов во время игры.

## запуск и сборка

Требуется Node.js 20 или новее.

```sh
npm run dev
```

Открыть http://127.0.0.1:8765/. При занятом порте: `npm run dev -- --port 8766`.
Двойной клик по HTML не подходит: модели загружаются через HTTP.

```sh
npm run build
npm run preview
```

`dist/` содержит только файлы игры, ассеты, лицензии и SHA256-манифест релиза.
Для публикации на GitHub Pages или другом статическом хостинге скопировать содержимое
`dist/` в корень сайта. Сервер приложения не нужен. Размер сборки — около 20 МБ.

## управление

| Действие | Управление |
|---|---|
| Ходьба относительно камеры | WASD / стрелки |
| Прицел сопла | курсор мыши |
| Прыжок | пробел |
| Всасывание | удерживать ЛКМ / F |
| Свободный обзор по двум осям | ПКМ + мышь |
| Поворот камеры | Q / E |
| Расстояние камеры | колесо |
| Камера за спиной | V |
| Игровой обзор с захватом мыши | M; Esc — вернуть курсор |
| Пауза / продолжение | P |
| Перезапуск уровня | R |
| Скрыть / показать интерфейс | H |
| Продолжить после результата | Enter |

Если захват мыши недоступен, M включает обзор перетаскиванием ЛКМ, всасывание — F.
Кнопки звука и полного экрана находятся в панели управления. Выбор звука сохраняется
локально. При уходе с вкладки игра приостанавливается.

## изменения версии 1.0.3

- Полная длина шланга зафиксирована на 2,5 м: от выхода сумки через ладонь до
  сопла. При близком прицеле запас длины складывается в изгиб; дальний прицел
  останавливается на пределе. Число колец гофры постоянно.
- Ограничение учитывает высоту руки, ходьбу, прыжок и заполнение сумки. До дальних
  вещей нужно физически подойти; подсказка показывает, когда шланг не достаёт.
- Пройдены три уровня с исходной раскладкой и перемещением клавишами. Отдельно
  проверены 425 точек стола, 45 исходных предметов и 26 точек узкой полосы пола у
  стены при пустой и полной сумке. Длина выбрана с запасом для подбора упавших вещей.
- Регрессионные проверки измеряют всю осевую линию и реально рисуемую трубку,
  крепления к сумке и ладони и невозможность всасывания дальнего предмета с места.

## изменения версии 1.0.2

- Пробел — одиночный прыжок с поджатыми коленями и приземлением; удерживание не
  запускает следующий прыжок. Во время прыжка можно двигаться; пауза останавливает
  полёт, перезапуск возвращает героиню на пол. Всасывание — ЛКМ или F.
- Тонкие предметы размещаются над видимой тканью с учётом складок и всего размера
  модели. Исправлены скрытые под скатертью ключи второго уровня; зубцы и кольца
  ключей лучше различимы. Положение на ткани сохраняется после отпускания пылесоса.
- Пальцы исходной текстурированной модели согнуты вокруг ручки сумки и шланга;
  крепления следуют за ладонями, а направление шланга согласовано с хватом.
- Проверки включают повторные прыжки, паузу в воздухе, видимость и прохождение
  второго уровня с исходной раскладкой предметов.

## изменения версии 1.0.1

- Исправлена доставка обновлений: сама страница, скрипты, стили, модели и текстуры
  больше не полагаются на `?release=` в адресе. Сборка ставит общий хеш содержимого
  в URL ресурсов; номер версии виден в стартовом меню.
- Широкоугольная камера: вертикальный угол 76°, более близкая дистанция и более
  низкий наклон. Прицел использует ту же проекцию; свободный обзор сохранён.
- Лёгкий цифровой шум под интерфейсом, без влияния на мышь. На паузе и при системной
  настройке уменьшения движения шум не анимируется.
- Видимость проверяется в полной комнате с настоящим материалом героини: 32 ракурса
  у стен и 24-секундный прогон обычными клавишами с 49 проверками изображения.

## изменения версии 1.0

- Исправлено исчезновение женщины при ходьбе: сохранён исходный масштаб скелета GLB,
  работает аппаратная анимация. Причиной был ошибочный перенос позы в сетку,
  увеличивавший персонажа примерно в 100 раз.
- Ходьба плавно смешивается с позой покоя, учитывает столкновения и уровень пола.
  Сумка и шланг следуют за ладонями; выход шланга совмещён со стенкой сумки.
- Камера больше не скрывает персонажа у стены; есть обход тесных участков.
- Комната приближена к видео: гладкие светлые стены, серый матовый пол, светлая ткань
  со складками, винная юбка стола, рассеянный свет и детали балкона.
- Старт доступен после полной загрузки. При ошибке доступна повторная попытка.
  Пауза замораживает предметы, в том числе уже находящиеся в шланге.
- Геометрия шланга обновляется в существующих буферах. Модели уменьшены с 16,6 до
  5,4 МБ перекодированием текстур; геометрия, веса и анимации сохранены побайтно.

Это стилизованная реконструкция с объёмной сценой и свободной камерой. Она не является
точной копией видео: лицо, хват кистей и складки отличаются; дальний пейзаж за окном —
фотографическая плоскость. Симуляции ткани и волос нет. Сенсорное управление не заявлено.

## проверка

```sh
npm ci
npm run test:install
npm test
```

Playwright нужен только для тестов. Проверки запускают временный локальный сервер;
используется установленный Chrome или загруженный Chromium. Результат сохраняется
в `review/browser-checks.json`, снимки — в `review/`.

Проверяются все уровни, ловушки, камера, столкновения, пауза, перезапуск, загрузка и
восстановление после ошибки. Анимация проверяется после загрузки GLB: размер модели,
изменение ног, видимость реальных пикселей при W/A/S/D и крепления предметов.
Один тест на конечные координаты для этого недостаточен.
Проверка доступности предметов: `node scripts/hose-reach-check.cjs` (сервер на 8766;
другой адрес через `GAME_URL`).
Дополнительный прогон реального управления: `node scripts/visibility-smoke.cjs`.
Для готовой сборки: `GAME_DIR=dist node scripts/visibility-smoke.cjs`.
С `QA_VIDEO=1` также записывается видео (нужен FFmpeg из Playwright).

Исходная сборка поддерживает `/?qa=1` и отладочный `window.GAME`. В `dist/` тестовый
скрипт не включён. Визуальная проверка и её ограничения — в `design-qa.md`;
происхождение ассетов — в `assets/README.md`.
