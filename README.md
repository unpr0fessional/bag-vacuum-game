# bag-vacuum-game — «сумка-пылесос»

Браузерная 3D-игра по видео `сумкапылесос_1_2+саунд.mp4` (практика 9, 23.09.26).
Один файл `index.html`: HTML + CSS + чистый JavaScript + Three.js r128 с CDN.
Сборщиков, модулей и внешних ассетов нет. Модели, текстуры и звук генерируются кодом.

**Запуск:** двойной клик по `index.html` → откроется в браузере (нужен интернет для Three.js).

## Что происходит в игре

Героиня в чёрной коже с капюшоном держит в правой руке сумку. Из сумки выходит гофрированный
шланг пылесоса, конец шланга у неё в левой руке. На столе (белая скатерть, малиновое основание,
окно с балконом за столом) лежат деньги, золото, ключи и косметика.

- **Цель уровня:** всосать в сумку всё из **заказа** (список слева сверху).
- **Нельзя:** всасывать лишнее. Всё, чего нет в заказе, — лишнее.
- **Индикатор сумки** (справа снизу): лишнее занимает место. Если заполнить больше 100% —
  «сумка лопнула», проигрыш. Зелёная черта показывает, сколько займёт весь заказ.
  Вместимость = объём заказа × 1.3 (`CONFIG.bag.capacityFactor`).
- **Окно «внутри сумки»:** отсылка к финальному кадру видео. Там видно, что уже лежит в сумке.
- **Ловушки:** `пачка с краской` (похожа на деньги, красная бандероль, на экране розовая клякса,
  занимает много места) и `GPS-метка` (мигает, отнимает 10 секунд).
- **Таймер:** время вышло — проигрыш.
- **Вид от третьего лица:** камера сзади, через правое плечо. Если героиня закрывает сопло,
  она становится полупрозрачной.

Уровни: `разминка` → `косметичка` → `как в видео` (в заказе ровно то, что было в сумке
в финале ролика: деньги, цепи, ключи, автоключ, розовый блеск).

### Управление
| клавиша | действие |
|---|---|
| W A S D / стрелки | идти (относительно камеры) |
| мышь | куда смотрит сопло. Наводишь на стол — сопло поднимается на уровень стола; на пол — опускается к полу. Шланг достаёт на 1.7 м (`CONFIG.hose.reach`): если дальше, сопло висит у края досягаемости и внизу подсказка «подойди ближе» |
| ЛКМ или Space (держать) | всасывание |
| Q / E, правая кнопка + drag | повернуть камеру |
| колесо | камера ближе/дальше |
| R | начать уровень заново |
| Enter | дальше (после победы) / заново (после проигрыша) |

## Архитектура кода (для LLM и людей)

Весь код в одном `<script>`. Разделы помечены `§N` — ищи по ним.

| раздел | что там |
|---|---|
| §1 `CONFIG` | все числа: размеры комнаты и стола, скорость, длина шланга, радиус всасывания, камера, размер окна-сумки |
| §2 `ITEM_TYPES` | каталог предметов: `name`, `volume` (место в сумке), `value` ($), `weight` (скорость притяжения), `r` (радиус на столе), `effect`, `build()` (3D-модель) |
| §3 `LEVELS` | уровни: `name`, `brief`, `time`, `targets` {тип: кол-во} = заказ, `extras` {тип: кол-во} = лишнее |
| §4 | утилиты (`damp`, `clamp`, `canvasTexture`), текстуры `TEX`, материалы `M`, функции `buildCash()`, `buildChain()`… |
| §5 | сцена: renderer, комната, окно, стол (`surfaceHeightAt(x,z)`), стул, свет |
| §6 | персонаж `hero` и состояние `player` {pos, yaw, moveAmount, walkPhase} |
| §7 | сумка `bag` (раздувается от заполнения), шланг `hoseCurve` (CatmullRom → TubeGeometry, пересобирается каждый кадр), сопло `tip`, кольцо зоны всасывания |
| §8 | предметы `items[]`: раскладка `spawnLevelItems()`, физика и всасывание `updateItems()`, `startHoseTravel()`, `putIntoBag()` — тут начисление, ошибки, эффекты, проверка победы/проигрыша |
| §9 | `bagView` — вторая сцена «внутри сумки», рисуется в угол экрана через scissor |
| §10 | ввод `input` и `computeAimTarget()` (луч от мыши → стол/пол → ограничение длиной шланга) |
| §11 | камера `updateCamera()`, полупрозрачность героини, ходьба `updatePlayer()`, коллизии `resolveCollisions()` |
| §12 | HUD: `renderOrder()`, `updateHUD()` (таймер, индикатор сумки, подпись предмета под соплом), `toast()`, `showOverlay()` |
| §13 | `Sound` — WebAudio: шум воздуха + мотор при всасывании, «глоток», ошибки, победа |
| §14 | `game` (состояние), `startLevel()`, `endLevel()`, `showIntro()`, `step(dt)` — один шаг симуляции, `render()`, `frame()` — цикл |
| §15 | `window.GAME` — debug API |

### Жизненный цикл предмета
```
rest ──(сосём, ближе pullRadius)──► pulled ──(ближе swallowDist)──► hose ──(travelTime сек)──► bagged
  ▲                                   │
  └────────(отпустили кнопку)─────────┘   (падает обратно с гравитацией)
```
В состоянии `hose` сам предмет скрыт, по шлангу от сопла к сумке едет «горб» (`bulge`).
В `bagged` вызывается `putIntoBag()`: `game.fill += volume`, заказ/ошибка/эффект,
копия модели падает в окно «внутри сумки».

### Состояния игры
`intro` → `playing` → `won` | `lost` → следующий уровень / заново.

### Координаты
Метры, Y вверх. Окно на задней стене `z = -halfD`. Стол в `CONFIG.table`. Игрок стартует
в `CONFIG.player.startX/startZ` лицом к столу (−Z). `player.yaw = 0` — смотрит на −Z.

## Как менять (типовые правки)

- **Новый предмет:** добавить `buildX()` в §4 (модель лежит на столе, низ на y = 0),
  затем строку в `ITEM_TYPES` (§2). Использовать в `targets` или `extras` уровня.
- **Новый уровень:** дописать объект в `LEVELS` (§3). Кнопка на старте появится сама.
- **Сложность:** `CONFIG.bag.capacityFactor` (запас места), `CONFIG.suction.pullRadius`
  (насколько широко тянет), `LEVELS[i].time`, `CONFIG.items.scale` (размер вещей).
- **Новый эффект ловушки:** поле `effect` в `ITEM_TYPES` + ветка в `putIntoBag()` (§8).
- **Камера:** `CONFIG.camera` (дистанция, высота, плечо, насколько смотреть на сопло).

### Debug API в консоли браузера
```js
GAME.start(2)            // сразу уровень 3
GAME.aim(0.2, -1.3)      // навести сопло на точку (x, z); GAME.aim(null) — вернуть мышь
GAME.suck(true)          // включить всасывание
GAME.items               // все предметы уровня
GAME.game                // fill, capacity, timeLeft, collected, mistakes…
GAME.step(1/60)          // прогнать один кадр вручную
```
